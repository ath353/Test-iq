# Luyện Test IQ

Web luyện các dạng bài test năng lực khi tuyển dụng. Thông tin đầy đủ về dự án xem tại [CLAUDE.md](CLAUDE.md).

## Chạy dự án

```bash
npm install     # cài thư viện (lần đầu)
npm run dev     # chạy bản phát triển tại http://localhost:5173
npm run build   # build bản chạy thật vào thư mục dist
```
